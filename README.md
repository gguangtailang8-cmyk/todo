# 📝 My ToDo List

PythonとFlaskを使って制作したシンプルなToDoアプリです。

## 概要

タスクの追加・編集・削除・完了状態の管理ができるWebアプリです。

## 主な機能

- タスクの追加
- タスクの編集
- タスクの削除
- タスクの完了・未完了切り替え
- 未完了・完了タスクの件数表示
- SQLiteによるデータ保存
- レスポンシブ対応
- 削除前の確認ダイアログ

## 使用技術

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript

## 制作目的

PythonとWebアプリ開発の基礎を学ぶために制作しました。

Flaskを使ったルーティング、フォーム処理、SQLiteとのデータ連携、
HTML/CSSによる画面作成などを実践的に学習しました。
